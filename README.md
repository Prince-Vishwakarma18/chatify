# Chatify 💬

A real-time chat application built using MERN stack, Socket.io, and Cloudinary. Includes image upload, online status, and live messaging , search user and update profile.

## Features
- User authentication
- Real-time messaging
- Responsive UI
- Modern chat interface
- Update profile

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB
- Real-time: Socket.io
